Hollowbloom - a cozy farm above an endless Hollow

For Linux handhelds such as the Anbernic RG351P, RG351M and RG351V, on ArkOS, AmberELEC,
ROCKNIX and the like (64-bit ARM).

INSTALLING

  Copy Hollowbloom.sh and the hollowbloom folder into your ports folder: roms/ports on the
  games card (roms2/ports on ArkOS with two cards, /storage/roms/ports on AmberELEC). Restart
  EmulationStation, or update the game lists, and Hollowbloom is under Ports.

CONTROLS

  Left stick, D-pad   walk                  Right stick   aim
  A                   talk, open, OK        B             roll, back
  X                   use tool or weapon    Y             bag
  L1 / R1             hotbar, menu tabs     L2 / R2       cast your two spells
  Select              crafting book         Start         pause
  L3 / R3             map / quest journal (also in the pause menu)

  Hold Select and Start together for a second to save and quit.

  If A and B (and X and Y) come out the wrong way round, open Hollowbloom.sh in a text
  editor and remove the # in front of "export HOLLOWBLOOM_SWAP_AB=1".

GOOD TO KNOW

  Saves go in the hollowbloom folder, beside the game (save.json). If the game won't
  start, hollowbloom/log.txt says why.
  Sun shadows and ambient occlusion start off to keep it quick; turn them on under
  Pause > Settings if your handheld keeps up.
